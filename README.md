# Titanic Data Analysis

## About the Project
This project performs Exploratory Data Analysis (EDA) on the Titanic passenger dataset using Python. It analyses passenger survival based on gender, age, passenger class, ticket fare, and family size.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Features
- Data cleaning and handling missing values
- Survival rate analysis
- Gender-wise survival analysis
- Passenger class analysis
- Age group analysis
- Family size analysis
- Data visualization using charts
- Exporting cleaned data and reports

## Visualizations
1. Survival Count
2. Survival Rate by Gender
3. Survival Rate by Passenger Class
4. Age Distribution
5. Fare Comparison
6. Correlation Heatmap

## Key Findings
- Overall survival rate: 38.38%
- Female survival rate: 74.20%
- Male survival rate: 18.89%
- First-class survival rate: 62.96%
- Third-class survival rate: 24.24%

## How to Run

1. Clone or download this repository.
2. Install the required libraries:

```bash
pip install pandas matplotlib seaborn
```

3. Run the Python file:

```bash
python titanic_analysis.py
```

## Dataset
The project uses the Titanic passenger dataset containing 891 rows and 12 columns.
